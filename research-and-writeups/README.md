### 03 — Cybersecurity Home Lab

**UGREEN NASync DXP8800 Plus | 80 TB Raw Storage | Self-Hosted Infrastructure**

A long-term home lab built around eight 10 TB hard drives with ZimaOS, TrueNAS, and Docker.

The environment supports:

- Network-attached storage
- Pi-hole DNS filtering
- Plex / Jellyfin media services
- Immich family photo storage
- Tailscale secure remote access
- Linux and Docker administration
- Storage, networking, and cybersecurity experimentation
