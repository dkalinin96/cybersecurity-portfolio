# PNC Technology Bootcamp - Final Reflection

**Week 12, Day 3 | October 21, 2026**

After 12 weeks of cybersecurity training, I wanted to reflect on the lessons, technical concepts, and challenges that stood out throughout the program.

---

## 1. Top 3 Memorable Quotes and Lessons

These are paraphrased lessons from the course, rather than verified direct quotations.

### 1. "Security is not a one-time configuration. It is a continuous process."

One of my biggest takeaways was that cybersecurity requires constant monitoring, patching, testing, and improvement. Hardening a system is only the beginning.

### 2. "An alert tells you something happened. An investigation tells you why."

During our SOC investigations, I learned that identifying suspicious activity is only one part of the process. Understanding the root cause, reconstructing the attack, and determining the impact are equally important.

### 3. "You cannot protect what you do not understand."

This became particularly relevant during our Azure security capstone. Before implementing security controls, we needed to understand the environment, establish baselines, and identify vulnerabilities.

---

## 2. Five Technical Concepts That Interested Me

### 1. Linux and Windows System Hardening
I enjoyed learning how to secure operating systems through SSH configuration, firewall policies, password requirements, privilege restrictions, and audit logging.

### 2. Security Information and Event Management (SIEM)
Learning Splunk SPL and Microsoft Sentinel KQL helped me understand how security teams analyze logs, correlate events, and identify suspicious activity.

### 3. Network Traffic Analysis and Intrusion Detection
Using Wireshark and Snort to analyze network packets, identify anomalies, and create detection rules helped connect networking fundamentals with practical security monitoring.

### 4. Azure Cloud Security
Working with Azure virtual machines, Network Security Groups, role-based access control, and network segmentation was particularly interesting. Our capstone allowed us to apply these concepts to a simulated financial institution.

### 5. Digital Forensics and Incident Response
I enjoyed reconstructing attacker timelines, identifying indicators of compromise, investigating lateral movement, and developing containment and recovery strategies.

---

## 3. Seven Complex Concepts I Did Not Fully Understand Before the Bootcamp

### 1. Public Key Infrastructure (PKI) and Certificate Chain Validation
I developed a deeper understanding of how certificate authorities establish trust, how certificate chains are validated, and how insecure TLS configurations affect security.

### 2. ARP Poisoning and Man-in-the-Middle Attacks
I learned how attackers manipulate ARP tables to intercept network traffic, the role of IP forwarding, and how Dynamic ARP Inspection and DHCP snooping can help prevent these attacks.

### 3. MITRE ATT&CK and the Pyramid of Pain
I learned how security teams categorize adversary behavior using MITRE ATT&CK and why detecting attacker techniques can be more effective than relying exclusively on IP addresses or file hashes.

### 4. Lateral Movement and Attack Chain Reconstruction
I learned how attackers move between systems using compromised credentials and legitimate remote access protocols. Investigating these movements required correlating logs across multiple hosts.

### 5. Detection Engineering and Behavioral Analytics
I learned how security analysts develop detection rules, identify suspicious patterns, correlate events, and reduce false positives while maintaining effective threat detection.

### 6. Security Orchestration, Automation, and Response (SOAR)
I learned how security teams automate repetitive tasks, enrich alerts with additional context, and coordinate incident response while maintaining appropriate human oversight.

### 7. PCI DSS Compliance and Evidence-Based Security Validation
Our Azure capstone helped me understand how technical security controls connect to compliance requirements. Implementing a security control is not enough. Teams must document configurations, validate effectiveness, and preserve supporting evidence.

---

## 4. Final Reflection

The PNC Technology Bootcamp helped bridge the gap between academic cybersecurity knowledge and practical enterprise security operations.

Throughout the program, I gained hands-on experience in system hardening, network security, threat detection, incident response, cloud infrastructure, and compliance.

One of my biggest takeaways is that cybersecurity involves more than technical knowledge. Communication, documentation, teamwork, critical thinking, and adaptability are equally important.

As I begin the next stage of my career, I look forward to continuing to develop my skills in security engineering, threat detection, cloud security, and incident response.

**The end of the bootcamp marks the beginning of applying these skills in a professional environment.**
